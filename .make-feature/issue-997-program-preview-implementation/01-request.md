## 4. Раздели пользовательские действия

Реализуй и проверь независимые действия:

**Посмотреть**

Открывает предпросмотр без изменений состояния программы.

**Выбрать**

Фиксирует выбор на уровне интерфейса, не назначая программу автоматически.

**Создать копию**

Открывает существующий механизм создания личной копии.

**Редактировать**

Доступно только при наличии соответствующих прав.

**Назначить**

Проверяет актуальность программы и открывает существующий сценарий настройки расписания.

**Заменить активную программу**

Требует явного подтверждения и соблюдения серверных ограничений.

**Закрыть**

Закрывает предпросмотр без изменения данных, возвращает фокус на исходный элемент.

Запрещены неявные изменения active program при просмотре, выборе, копировании или закрытии.
