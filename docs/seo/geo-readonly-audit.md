# Бесплатный GEO-аудит публичных страниц - добровольный пилот (#1224)

**Назначение:** операторская диагностика фиксированных публичных канонических URL YFC с помощью [Auriti-Labs/geo-optimizer-skill](https://github.com/Auriti-Labs/geo-optimizer-skill) (MIT). Это дополнительная внешняя проверка, а не новый SEO-контроллер и не производственный сервис. За корректностью `robots.txt`, `sitemap.xml`, canonical и HTML уже следит `scripts/check_seo_surface.py`.

## Использование без установки

```sh
# Внутренний предпросмотр, без сетевых обращений и запуска внешних программ:
python scripts/geo_readonly_audit.py --route /nutrition --route /training

# Только по отдельному решению оператора и после локальной проверки установки:
python scripts/geo_readonly_audit.py --execute --route /nutrition
```

Скрипт принимает только опубликованные маршруты: `/`, `/training`, `/nutrition`, `/calculators/1rm`, `/programs/full-body-3-days`, `/for-trainers`. Другие пути (включая `/app`, `/api`, `/admin`) и произвольные домены не поддерживаются. `--execute` вызывает **только** `geo audit --url <canonical URL>` через аргументы без оболочки, с ограниченным временем и очищенным окружением. CLI не устанавливается автоматически; при его отсутствии запуск завершается с `GEO_READONLY_NOT_VERIFIED`.

Тесты адаптера без внешнего пакета и сети:

```sh
python -m pytest tests/test_geo_readonly_audit.py -q
```

Установка, выбор версии и проверка исходного кода GEO Optimizer остаются добровольным отдельным действием оператора вне production и этого скрипта. Перед выполнением нужно убедиться, что локальная команда `geo` соответствует проверенному релизу разработчика и не имеет неожиданных побочных эффектов. Для этого пилота не нужны API-ключи, платные услуги и соединение с учётными записями Google/Яндекс.

## Интерпретация

- `PREVIEW_ONLY` означает только сформированный план, **не** выполненный аудит.
- `CLI_EXIT_ZERO` означает, что сторонняя программа завершилась успешно. Её балл 0-100 - собственная эвристика, а не доказательство индексации, поискового спроса, посещений или цитирования ChatGPT/Google.
- `NOT_MEASURED` для реальных упоминаний ИИ не является нулём. Здесь **не** используется платная команда `geo citations`, сбор выдач LLM или другие API.
- Реальные запросы, показы, клики и позиции проверяются отдельно по GSC и Яндекс Вебмастеру в [YFC #320](https://github.com/MikeMoore1337/your-fitness-coach/issues/320) и [Hermes #191/#397](https://github.com/MikeMoore1337/hermes/issues/191).
- Не используются `geo fix`, `--apply`, публикация, изменение `robots.txt`, `llms.txt`, JSON-LD или SEO-контента. Любые исправления требуют отдельного доказательного решения владельца в существующей SEO-дорожной карте [#324](https://github.com/MikeMoore1337/your-fitness-coach/issues/324).

Скрипт не добавлен в периодические задания, обязательные сетевые CI и production runtime. Исходный код внешнего проекта не включён в YFC, локальные отчёты в репозиторий не сохраняются.
