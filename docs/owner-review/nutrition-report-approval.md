## Условия утверждения

Подтверждено визуальное решение для уже реализованных данных и интерфейсных компонентов. Утверждение не расширяет объём до микронутриентов, витаминов, трекера привычек или новых медицинских рекомендаций. Отсутствующие данные клетчатки не считаются нулём; нормы клетчатки не выдумываются; доступ тренера к чужому дневнику не расширяется.

Доставка: только штатный CI и подтверждённый production deploy; успешный PR CI или `workflow_dispatch` сам по себе не подменяет обязательный push-trigger CI в защищённом `master`.
