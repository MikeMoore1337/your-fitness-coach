# #916: ограниченный этап цикла недель

Этот Draft PR добавляет только сохранение необязательного цикла при создании шаблона через существующий API программ. `week_cycle` содержит `schema_version: 1`, непустой список `week_types` (`light`, `medium`, `heavy`) и явный boolean `repeat`. Порядок произвольный; длина цикла не ограничена 24 неделями, но остаётся ограничение размера HTTP-запроса. Отсутствие поля оставляет старую программу без цикла и не назначает ей `medium`.

Цикл хранится внутри существующего `program_metadata`; клонирование тренером сохраняет его, account export использует существующий экспорт метаданных. Миграции нет. Этот этап **не реализует назначение, изменение цикла, повторение, идентичность материализованных недель или сохранение типа в фактах тренировок**. Попытки назначения шаблона с циклом, редактирования цикла и публикации такой программы отклоняются: так цикл не теряется при share и не выглядит применённым к тренировкам. Существующие программы без поля продолжают прежний путь. Это временная граница, не завершение #916.

Для следующего этапа необходимы ограниченная материализация назначений, привязка фактов к неизменяемым snapshots, version/conflict и конкурентные проверки на PostgreSQL, совместимость импорта, экспорта, генератора и Coach OS. Нельзя снимать эти ограничения одной лишь заменой лимита 24 недель: текущий assignment создаёт всю серию сразу. Визуальные элементы остаются за отдельным согласованием #918.
