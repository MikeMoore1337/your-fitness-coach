# Атрибуция внешних UI-справочников

Копии в `.agents/references/external-quality/` распространяются с сохранением
атрибуции. Точные upstream файлы, commit и Git blob SHA - в
[external-ui-sources.json](external-ui-sources.json).

- **Vercel Labs**: [vercel-labs/agent-skills](https://github.com/vercel-labs/agent-skills), React Best Practices и Composition Patterns, лицензия MIT по метаданным skill/README.
- **Ibelick**: [ibelick/ui-skills](https://github.com/ibelick/ui-skills/blob/main/LICENSE), доступность, motion, review и metadata, MIT.
- **Leonxlnx**: [leonxlnx/taste-skill](https://github.com/leonxlnx/taste-skill/blob/main/LICENSE), redesign, MIT.
- **NextLevelBuilder**: [ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill/blob/main/LICENSE), дизайн-каталоги, MIT.
