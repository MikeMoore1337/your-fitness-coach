# Landing — кандидат нового визуального эталона

**На рассмотрении.** Это фактические снимки изолированного Windows DEV, не production. Исходный код: [c9f05232737f](https://github.com/MikeMoore1337/your-fitness-coach/tree/c9f05232737f9072eb7716c120426a52ae990ad7); связанные задачи [#1545](https://github.com/MikeMoore1337/your-fitness-coach/issues/1545) и [#1422](https://github.com/MikeMoore1337/your-fitness-coach/issues/1422). Существующие файлы V10 и проверки не изменены.

- Страницы сняты в Windows: Chromium 151.0.7922.34, Firefox 153.0 и WebKit 26.5; DPR 1. Первые экраны и архивные сцены показаны во всех трёх браузерах, дополнительные состояния и полные страницы — в Chromium.
- Данные и ответы API синтетические, сторонние запросы блокировались, авторизация и пользовательские данные не использовались. Скриншоты сделаны на проверенном DEV SHA. Для большинства кадров включён reduced motion; у демонстрации подхода использовались штатные кнопки фаз.
- JPEG — сжатые **превью для просмотра**: качество 35 у четырёх длинных desktop-страниц, 75–80 у остальных кадров. [Манифест](manifest.json) содержит качество и SHA-256 каждого JPEG и исходного PNG. Полные PNG доступны в локальной галерее; [PNG-артефакт GitHub Actions](https://github.com/MikeMoore1337/your-fitness-coach/actions/runs/46137611374/artifacts/15260452806) содержит снимки первого экрана и архивных сцен того же SHA. Сам visual run завершился FAIL из-за несовпадений с прежним эталоном. JPEG не применяются как пиксельный baseline.
- ACTIVE_COMPARABLE — старое сравнение остаётся действующим. OWNER_SUPERSEDED — старая сцена была заменена; приведённая текущая секция не является пиксельным совпадением с архивом. В некоторых нижних заменённых секциях отдельный визуальный эталон ранее не был подтверждён.
