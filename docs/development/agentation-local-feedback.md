# Agentation: локальные визуальные замечания для YFC (#1231)

**Режим:** отдельный opt-in инструмент разработки, а не продуктовая функция. Он не появляется в собранном production, Telegram Mini App или опубликованном приложении. Пользовательский дизайн YFC не изменяется.

## Запуск на своём компьютере

Agentation распространяется на условиях [PolyForm Shield 1.0.0](https://github.com/benjitaylor/agentation/blob/main/LICENSE), **не MIT**. Проверьте ограничения лицензии перед установкой. Проект не копирует и не распространяет его исходники. Версия зафиксирована в команде операторской установки, но не включена в штатный `npm ci` и `package-lock.json`.

```sh
cd frontend
npm ci --ignore-scripts

# Только если хотите запустить аннотации:
npm install --no-save --package-lock=false --ignore-scripts agentation@3.1.2

# macOS/Linux:
YFC_AGENTATION=1 npm run dev

# Windows PowerShell:
# $env:YFC_AGENTATION='1'; npm run dev
```

Откройте **на этом же компьютере** `http://127.0.0.1:5173/` в десктопном браузере с шириной от 768 px. Панель Agentation подключится только при `YFC_AGENTATION=1`; без переменной обычный `npm run dev` не загружает инструмент. Для отключения остановите сервер и очистите переменную. Для проверки только приложения используйте штатные команды без Agentation.

Важные границы:

- Только `vite serve` на loopback. Production `vite build` не импортирует `/devtools/agentation.jsx`. Никакого CDN, автоустановщика, POST/webhook или MCP-подключения нет.
- Приложение остаётся закрытым для регистрации нового UI без предварительного визуального согласования. Annotating и Copy не заменяют PNG/HTML галерею, Playwright, сравнение Dark/Light, согласование владельца или релизный gate.
- Используйте **только синтетические или demo-данные**; не размечайте персональные записи, токены, сообщения, ключи и приватный кабинет других пользователей. Agentation может включать видимый текст, CSS-селекторы и DOM-метаданные в скопированную заметку: проверяйте и удаляйте чувствительные детали **до передачи** в Codex/ChatGPT/GitHub.
- Версия для мобильного браузера не заявлена (это desktop-инструмент); мобильные состояния сохраняют независимую проверку Playwright с viewports 320/393 px.
- Не запускайте `agentation-mcp` автоматически, не создавайте сервер HTTP или авторизованные действия из аннотаций.
- Отсутствие установленного optional Agentation = инструмент недоступен, но сборка, тесты и production не должны ломаться. Пилот сам по себе не подтверждает успешный запуск внешней библиотеки на рабочем ПК.

## Передача замечания

Для каждого замечания зафиксируйте route, состояние, viewport, тему, точный Git SHA, скопированный проверенный selector/путь элемента, краткую проблему и ожидаемый результат. Сохраняйте исходные и исправленные реальные скриншоты в **артефактах задачи YFC**, не в Toolkit. Одна отметка - не доказательство дефекта, а место для проверки.

Проверки интеграции: `npm run typecheck`, `npm run lint`, `npm run format:check`, `npm run test`, `npm run build`, `npm run perf:check` (с `YFC_AGENTATION` выключенным). При необходимости проверьте исходный asset manifest: `agentation` не должен присутствовать в production JS и CSS.
