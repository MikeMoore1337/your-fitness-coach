# #828 — реальные AFTER-скриншоты

Снимки сделаны с работающего React-интерфейса этой ветки после реализации. Кнопки,
уведомления и диалоги отображены приложением, без добавления элементов в DOM тестом.
API и буфер обмена управляются тестовыми ответами; все данные синтетические.
Снимки не подтверждают работу на физическом устройстве или в настоящем Telegram.

Mobile: viewport 393 × 844 CSS px. Desktop: 1280 × 900 CSS px. WebKit использует
масштаб устройства 2, поэтому размеры PNG больше размера viewport.
В сценариях также проверены ширины 320, 360 и 430 CSS px в обеих темах.
