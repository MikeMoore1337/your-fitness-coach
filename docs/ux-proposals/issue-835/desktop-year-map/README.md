# #835 — компактная desktop-карта года

Мобильная карусель одного месяца принята владельцем. Этот пакет предназначен для новой приёмки desktop; прежние desktop-карточки 3×4 и раскрытие большого месяца заменены единой годовой картой.

## Реализация

- Недельные колонки, 7 строк Пн–Вс, подписи месяцев, ячейки 10–14 CSS px с промежутками 2 px. Ячейки ограничены размером, а не растягиваются на весь широкий контейнер. При недостатке ширины прокручивается только карта; документ не получает горизонтального переполнения.
- Обычно 53 календарные колонки. Для високосного года, начинающегося в воскресенье (например, 2012), нужны 54 частичные календарные недели при строках Пн–Вс. Все 366 дат сохранены; это покрыто тестом.
- Заголовок «Активность» и выбор года в одной строке; timezone второстепенный. Диапазон года не повторяется. Предупреждение «История неполная» раскрывает число недатированных тренировок и объяснение ограничений. Будущие дни обозначены в легенде.
- Наведение показывает дату, тренировки и рабочие подходы. Подсказка допускает наведение и закрывается клавишей отмены; после выбора дня она убирается, чтобы постоянные показатели были видны.
- Одна Tab-остановка внутри карты. Влево/вправо — соседняя неделя, вверх/вниз — день внутри недели; Home/End — край строки, Ctrl+Home/End — край года. Ввод/пробел выбирают день. Выбор, фокус и фактическая активность имеют отдельную семантику.
- Нативная таблица по дням сохранена. Неизвестное не подменяется нулём, будущие дни отключены. Backend, API, миграции и семантика активности этой доработкой не менялись.

## Настоящий AFTER

Все кадры сделаны в реальном экране «Прогресс → Тренировки» локального приложения с синтетическим API. Личные данные владельца не использовались. Тестовое имя в кабинете — fixture.

Браузеры: Chromium, WebKit. Темы: Dark/Light. Desktop: 1024×844, 1280×844, 1440×1000, 1920×844. Дополнительно 768×844 и мобильная регрессия 320/360/390/430×844. У WebKit PNG может иметь больше физических пикселей из-за device scale factor.

- overview: текущий год с неполной историей; полный экран приложения.
- history-details: раскрытое объяснение неполной истории.
- complete-year: 2022, полный подтверждённый год с активностью и нулями; полный экран приложения.
- active-year: 2024, високосный год с частично известной активностью; полный экран приложения.
- hover, selected, unknown, leap: подсказка, выбранный день с показателями, неизвестный день, 29 февраля.
- future, table, empty: будущие дни, таблица, подтверждённо пустой 2023 год.

Синтетические данные: в 2022 одна тренировка/4 подхода каждые пять дней, остальные дни — подтверждённый ноль. В 2024 положительные записи распределены по году, остальные дни неизвестны; есть одна недатированная тренировка. Текущий год ограничен 30 января для теста будущих дней. Эти данные не описывают реальную историю пользователя.

## Проверки и границы доказательств

- 1078 frontend unit-тестов / 166 файлов PASS до синхронизации dev; включая 365/366 дней, границы года и 54 колонки для 2012, roving focus и фактические подсказки. Полный локальный запуск с двумя workers; timeout проверки исходников под параллельной нагрузкой устранён снижением локальной параллельности, assertions/timeout не менялись.
- 36 E2E PASS: Chromium/WebKit × две темы × 320/360/390/430/768/1024/1280/1440/1920. Проверяются одна Tab-остановка, hover/click/клавиатура, размеры ячеек, смена года, високосный день, future/unknown/zero/empty, раскрытие истории, таблица, отсутствие перекрытия кнопкой «Добавить» и page overflow. Финальный результат и CI публикуются в #835 / PR #1317.
- Typecheck, lint, Prettier с CI-настройкой end-of-line auto, build и perf:check PASS. Финальный набор после синхронизации dev выполнен на исходниках `f843886c7c113309ceee1c1d0cc6eb9d71f0185e`; следующий коммит добавляет только этот визуальный пакет.
- Мобильная карусель не перерабатывалась. В регрессии Chromium проверяет настоящие touch-события, WebKit — нативную горизонтальную прокрутку/кнопки; физический iOS touch не подтверждён.
- Проверены DOM-семантика, фокус и клавиатура. Физический VoiceOver, другие настоящие экранные дикторы и Telegram WebView: NOT_VERIFIED. Полное соответствие WCAG по одной автоматизации не заявляется.
- Для приёмки требуется решение владельца только по новому desktop и этому AFTER. Мобильная версия уже принята. Merge/deploy требуют отдельного разрешения и не выполнялись. Env change required: no; ранее подготовленная миграция PR остаётся без изменений. #1201 BACKLOG/HOLD.
