## Полная матрица

`pages/` содержит полный экран «Прогресс → Тренировки» для Chromium и WebKit, тёмной и светлой тем, 1024 / 1280 / 1440 / 1920 px. На широких экранах данные выбранного дня расположены справа, на более узких — под картой.

`matrix/` содержит состояния `selected`, `unknown`, `empty`, `future`, `leap`, `table` и `history-details` для каждого сочетания браузера, темы и desktop-ширины. Имена файлов имеют вид `<browser>-<theme>-<width>-<state>.png`.

`states/` содержит дополнительные снимки самой карточки при 1440 px: день с активностью, подтверждённый ноль, неполная и пустая история, будущий день, високосный и граничный годы, таблица и пояснение о достоверности. `mobile/` содержит принятый месячный календарь для обоих браузеров и тем при 320 / 360 / 390 / 430 px.

Проверки: 40 браузерных сценариев матрицы и ещё 4 сценария сохранения фокуса при загрузке прошли в Chromium/WebKit; 1093 frontend unit-теста прошли. Клавиатура и доступная таблица проверены автоматизированно. Физические устройства и реальные экранные дикторы этим пакетом не подтверждаются.

Принятие макета разрешило реализацию; этот реальный AFTER ожидает отдельной визуальной приёмки. Merge и deploy не разрешены.
