# #1132: варианты для визуального рассмотрения

Оба варианта показывают независимые факты: A — две ячейки, B — две строки. Все значения синтетические. Дополнительно показаны первый рабочий подход, разминка без прошлой истории и длинные значения. `variants.html` — автономный эскиз, не приложение; кнопки и поля подхода не реализуют действия.

PNG сняты Playwright Chromium и WebKit на 360×800 и 1440×900, в тёмной и светлой теме. Проверен `scrollWidth <= viewport` в обоих браузерах и темах. Скриншоты не подтверждают реальный iOS/Safari, Telegram, screen reader или поведение клавиатуры. Они показывают композицию эскиза, не AFTER-реализацию.

[Фактический контракт](history-contract.md) ещё не реализован или протестирован. Любое UI-внедрение ждёт явного выбора владельца; после реализации нужны реальные AFTER-доказательства и отдельная приёмка.
