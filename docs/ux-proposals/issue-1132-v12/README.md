Ширины: 320, 360, 393, 430, 768, 1024, 1280, 1440 px. Высота: 844 px для mobile, 900 px для tablet/desktop. ## B: варианты кнопки подстановки

Все три варианта сохраняют две строки истории B. Они отличаются расположением действий:

1. **Две кнопки друг под другом** — прежнее расположение; вторая подставляет результат прошлого выполнения.
2. **Кнопка рядом с историей** — действие находится непосредственно у значения прошлой тренировки; сегодняшняя подстановка остаётся внизу.
3. **Две кнопки в один ряд** — оба источника рядом под завершением; подписи переносятся на узком экране.

Снимки сделаны в Chromium. В интерактивном HTML используйте `concept=b&reuse=stack`, `reuse=inline` или `reuse=split`; значения и история синтетические. Кнопка заполняет пустые поля только по нажатию и не завершает подход. Уже введённые значения, RIR и отметка отказа не изменяются. При отсутствии истории действие недоступно; прошлый результат первого подхода доступен независимо от отсутствия предыдущего подхода сегодня. API возвращает вес и повторы, но не исторические RIR и отказ. Проверки реального клиента описаны в разделе AFTER.

Проверены 300 комбинаций HTML-макета: 3 варианта × 5 состояний × 5 ширин × 2 темы × Chromium/WebKit. В том числе проверены подстановка в пустые поля, сохранение введённого значения, независимость источников, первый подход, отсутствие истории, размеры кнопок и взаимодействие при модельной клавиатуре. В вариантах 1 и 3 кнопки при открытой модели клавиатуры требуют прокрутки над схематичным таймером; после прокрутки нажатие проверено. Дополнительно в 24 комбинациях проверено сохранение выбранных RIR и отметки отказа. Это не проверка React или физического устройства.
