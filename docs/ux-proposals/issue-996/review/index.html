YFC / Issue #996

Быстрый выбор проверенной замены

PROPOSAL · НЕ PRODUCTION

Три компоновки одного безопасного контракта

Варианты сокращают визуальный поиск, но не меняют серверную проверку. В каждом варианте сначала выбирается кандидат из ответа GET alternatives, затем отдельным шагом строится preview, и только после него доступен apply.

Данные прототипа Обезличенная синтетическая фикстура, повторяющая форму существующего ответа API. Поиск и фильтры действуют только внутри уже возвращенного множества.
01

Быстрый список

Три лучших результата сразу, полный ответ — по запросу.

Сильная сторона: самый короткий путь к частой замене. Риск: длинный полный список требует аккуратного фокуса.
02

Нижний лист

Короткий выбор наверху, поиск раскрывается в отдельном слое.

Сильная сторона: спокойная иерархия на 360–430 px. Риск: дополнительный слой и возврат фокуса.
03

Сравнение

Исходное упражнение и выбранная замена видны рядом до preview.

Сильная сторона: меньше сомнений перед preview. Риск: больше вертикали и текста.

OWNER GATE

Что нужно утвердить

  1. Один из трех визуальных вариантов или точечные правки к нему.
  2. Показываем ли человекочитаемую причину из allowlist reason_keys; неизвестный ключ не должен превращаться в выдуманное обещание.
  3. Разрешается ли локальный поиск по полному ответу без нового API; при пагинации/лимите этот прототип блокируется до отдельного API-решения.
