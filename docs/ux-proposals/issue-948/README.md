## Замечание владельца

Текущий вариант PR #958 уже исправил существенное обрезание имени, но карточки слишком высокие, и отдельная нижняя строка со звездой / «Изменить» содержит много пустого пространства. Владелец потребовал: **сначала рисовать/показывать макеты и дожидаться owner approval; затем закреплённый утверждённый макет реализовать максимально точно 1:1.**

## Обязательная компоновка утверждённого макета

| Элемент | Вариант v1.0 (при ширине экрана 320 CSS px) |
|---|---|
| Общая ширина | Непосредственно в модальном контейнере: боковой отступ 20 px, карточка **280 px** |
| Высота | **Авто по контенту**; на референсе: выбранная 118 px; обычная 117-126 px; без отдельной пустой полосы действий |
| Скругление | **15 px** в данном типе карточек; не навязывать радиус нижнего dock |
| Межкарточный интервал | **12 px** |
| Внутренний горизонтальный отступ | **12-13 px** |
| Название | **Inter 12.7 px/18 px, weight 700**, в две или больше строк, максимум доступной ширины; не обрезать различающие слова |
| Звезда | Справа наверху в **отдельном доступном 44×44 px hit-target**; не отнимать отдельную строку |
| Калории/основа расчёта | Под названием, без ellipsis, пример: «130 ккал / 100 г» |
| Происхождение | Небольшая нейтральная метка внизу слева («Мой продукт» / «Проверено YFC») |
| «Изменить» | Только у собственных продуктов, **в одной нижней строке справа** от метки; доступная hit-area не менее 44×44; не создавать отдельную строку |
| Выбор | Весь **основной контент карточки** - нажимаемая область «Выбрать продукт»; семантика объяснена текстом над результатами. Звезда и «Изменить» - отдельные действия, без вложенных button и без выбора продукта |
| Selected | Тонкая лаймовая граница ~1.6 px, спокойная тонированная поверхность, **контрастный** текст; **не** сплошная ярко-лаймовая заливка |
| Обычное состояние | Нейтральная карточка с тонким контуром и разборчивым названием |
| Фото | **Не добавлять изображения продуктов** для данной UI-доработки |
| Темы | Сохранить паритет Dark/Light, использовать существующие YFC semantic color tokens, не переносить жёсткие HEX в компоненты без необходимости |

### Строгое соответствие и исключения

- Содержимое, позиции, иерархия, размеры и композиция **карточки** должны повторять SVG-референс в состоянии 320 CSS px максимально близко: no extra footer, no duplicated "Выбрать", no giant stars, no arbitrary redesign, no thumbnail.
- **Не менять** действующие title/search/keyboard/header/primary actions FoodPickerDialog только потому, что они присутствуют в изображении для контекста. В них уже есть отдельный scope #946.
- На 360/393/430px допускается увеличение полезной ширины, но **не** добавление новой полосы действий; длинные локализованные названия / 200% текста требуют динамического роста высоты вместо обрезания.
- Цвета реализовать через токены проекта и отличать `selected`, `pressed`, `focus-visible`, `disabled`; WCAG AA.
- Предусмотреть самостоятельное нажатие звезды и редактирования, keyboard Tab/Space/Enter, screen reader labels. Избегать click-through и nested interactive elements.
- Не изменять калории, нутриенты, бренд, базу 100 г / 100 мл / порцию, поведение поиска и черновики пользователя.
