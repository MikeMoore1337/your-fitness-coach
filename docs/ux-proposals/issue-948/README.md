### Строгое соответствие и исключения

- Содержимое, позиции, иерархия, размеры и композиция **карточки** должны повторять SVG-референс в состоянии 320 CSS px максимально близко: no extra footer, no duplicated "Выбрать", no giant stars, no arbitrary redesign, no thumbnail.
- **Не менять** действующие title/search/keyboard/header/primary actions FoodPickerDialog только потому, что они присутствуют в изображении для контекста. В них уже есть отдельный scope #946.
- На 360/393/430px допускается увеличение полезной ширины, но **не** добавление новой полосы действий; длинные локализованные названия / 200% текста требуют динамического роста высоты вместо обрезания.
- Цвета реализовать через токены проекта и отличать `selected`, `pressed`, `focus-visible`, `disabled`; WCAG AA.
- Предусмотреть самостоятельное нажатие звезды и редактирования, keyboard Tab/Space/Enter, screen reader labels. Избегать click-through и nested interactive elements.
- Не изменять калории, нутриенты, бренд, базу 100 г / 100 мл / порцию, поведение поиска и черновики пользователя.
