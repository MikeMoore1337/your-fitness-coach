# Issue #1186 — wide-source motion review

The contact sheets cover all 77 canonical exercises with a wide approved poster/source. The
`posters-*.png` sheets compare the original 16:9 poster with center and focal square crops. The
`video-frames-*.png` sheets show the actual licensed MP4 at the first, middle and final reviewed
frames. `focal-candidates.png` is the focused comparison for the reviewed focal-point candidates.

Review result:

- 73 wide sources: safe filled-square `cover`; default center or a recorded per-source focal point;
- 4 wide sources: `contain-exception` because the reviewed crop loses a material body, implement,
  or movement path (`plank`, `push-up`, `reverse-crunch`, `side-plank`);
- 94 square sources: native 1:1 policy, no additional crop;
- 35 blocked catalog rows: no approved source, so no invented media or crop is applied.

The reproducible row-level matrix is [media-framing-matrix.json](../../media-framing-matrix.json)
and [media-framing-matrix.csv](../../media-framing-matrix.csv). These sheets are review evidence,
not a replacement for owner visual approval of the candidate.
