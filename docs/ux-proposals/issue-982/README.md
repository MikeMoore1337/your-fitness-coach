## Как посмотреть

1. [Скачайте prototype.zip](prototype.zip?raw=1), распакуйте и откройте `index.html` в браузере. В GitHub HTML отображается как исходный код. [Исходники лаборатории](lab/index.html) также включены отдельно.
2. Для WeekStrip, панели и Progress выберите «Спокойное»; для завершения — «Выразительное». Переключатель темы, кнопочные альтернативы и подробные инструкции доступны в лаборатории.
3. [Видео Native](video/chromium-native.webm?raw=1) · [видео Sport](video/chromium-sport.webm?raw=1). Chromium 393×852, автоматические действия; касания физического устройства не показаны.
4. [Таблица всех снимков](screens/README.md): Chromium/WebKit, 320/360/393/430 px, тёмная и светлая темы, все четыре сценария.

## Проверки

На этой версии лаборатории: [146 сценарных проверок](results/matrix.json), [32 reduced motion](results/reduced.json), [16 проверок графика и инструкций](results/owner-decisions.json), [9 проверок порогов](results/thresholds.json), [18 граничных случаев](results/edge-cases.json); Chromium 151 и WebKit 26.5. При проверке перехода недели основной сценарный тест устанавливает ленту у соответствующей границы; первый жест прокрутки отдельно проверен в `scroll-contract`. [Проверки исправлений](results/fixes.json) охватывают оба режима и движка; [прерывание недели](results/interruption.json) проверено отдельно. Тестируемые события отмены и ухода в фон синтетические.

Дополнительная [проверка размеров и исходного конфликта прокрутки](results/ergonomics.json) выявила ограничения, описанные в [спецификации](SPEC.md). Правило прокрутки сначала и смены недели новым жестом на границе проверено в [16 случаях](results/scroll-contract.json) и в [Chromium touch-эмуляции](results/scroll-touch.json). **Удобство порога человеком не подтверждено**: мышь и эмуляция показывают только геометрию и поведение. Impeccable ранее выполнен в режиме `DEGRADED: single-context`; независимая оценка отдельным специалистом в этой работе — `NOT_RUN`. Причина: ранее выбранный режим без субагентов и требование отдельно согласовать модель и условия каждого дополнительного вызова; такого согласия для этой консультации нет. Самооценка не выдаётся за независимую.

Реальные iPhone/Safari, Telegram WebView, системная клавиатура, VoiceOver, edge-back и производительность телефона — `NOT_VERIFIED`. Переключатель Telegram в лаборатории имитирует только кнопку «Назад». Визуальный пакет не подтверждает интеграцию, production или готовность к выпуску.
