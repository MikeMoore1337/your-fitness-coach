Питание клиента · макет #954

Один интерактивный прототип и снимки состояний. Все данные вымышлены, API не вызывается. Значения формы в примере не пересчитывают таблицу и не сохраняются.

Открыть интерактивный макет · выберите состояние и тему на панели макета. Откройте файлы через локальный HTTP-сервер из корня checkout.

Снимки: Microsoft Edge (Chromium), 390 × 844 и 1280 × 900 CSS px, две темы. Полные страницы показаны без фиксированной мобильной панели, чтобы она не перекрывала содержимое. Снимки экрана с панелью доступны отдельно.

Дополнительные проверки

На 320 × 720 сняты отчёт, проверка, предложение клиенту, конфликт, отсутствие доступа и пустые данные в двух темах. Эти же состояния проверены на переполнение при 320, 360, 390, 430 и 1280 CSS px. Проверены переходы по основному сценарию и отсутствие данных клиента на экране отозванного доступа.

Проверки относятся к прототипу, а не к API или production. WebKit, реальный Telegram WebView, физические устройства и скринридеры не проверялись.
