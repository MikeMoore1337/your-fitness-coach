# Issue #833: AFTER реализации импорта истории

Снимки настоящего интерфейса в локальной сборке после синхронизации с dev. Все данные и ответы API синтетические; сохранение в production не выполнялось.

Листы показывают панели в порядке 01–15: история, загрузка, обработка, предпросмотр, неизвестное и неоднозначное упражнение, сторона, RPE, конфликты, подтверждение, неизвестный результат, успех, черновик, устаревший просмотр и истечение срока.

На листах фиксированная нижняя навигация временно скрыта, чтобы она не перекрывала панель. В четырёх контекстных снимках навигация и остальная страница показаны без этого изменения. Снимки объединены без изменения масштаба; размеры ниже — CSS viewport. PWA и Telegram в тестах имитируются браузерными fixtures, а не реальными устройствами.
