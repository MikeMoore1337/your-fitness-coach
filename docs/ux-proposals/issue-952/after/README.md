# Issue #952 — фактические экраны после реализации

Снимки сделаны в Chromium на работающем локальном интерфейсе с вымышленными данными и контролируемыми ответами API. Это не production и не проверка физического устройства или настоящего клиента Telegram.

Отдельный сквозной Playwright-тест использует настоящий API и мигрированную тестовую PostgreSQL: сохранение одной даты, перезагрузка, отчёт и запрет изменения завершённого дня.

Размеры: 320×720, 390×844 и 1280×900; обе темы, reduced motion. Для мобильных экранов доступны полный снимок и текущий viewport с нижней навигацией.
