# #995: AFTER работающего интерфейса

Статус: **ожидает финальной визуальной приёмки владельца**. Макет был утверждён 30 октября 2026 года в чате Codex.
Все снимки сделаны с работающего React на синтетических данных; обычная матрица использует тестовые ответы API.
Отдельный [сквозной снимок](after/chromium-dark-393-integrated-postgres.png) получен через локальные FastAPI и PostgreSQL.

К утверждённой строке добавлен общий индикатор раскрытия YFC. Когда подсказка RIR видна, она находится перед заметкой: так сохраняется естественный порядок клавиатурного фокуса.

## Проверки

- Playwright: сценарии реального React с тестовыми API в Chromium и WebKit, все указанные ширины и темы, выбор меток, offline/reconnect, 409, редактирование, удаление и состояние после последнего подхода. Проверены отсутствие горизонтального переполнения, доступность поля при уменьшении viewport и попадание в кнопку завершения.
- Отдельно выполнен сквозной сценарий React → FastAPI → PostgreSQL на синтетической учётной записи: сохранение, offline, конфликт с другой версией, явное разрешение и сохранность фактических значений и API истории подходов.
- Размеры таймера и положение RIR и кнопки завершения сопоставлены до и после раскрытия блока. История подходов #1132 и общая заметка #1195 проверены отдельными регрессионными сценариями.
- Физические iPhone/Android, нативная клавиатура, реальное приложение Telegram и screen reader: `NOT_VERIFIED`. Браузерная имитация TMA не подтверждает поведение устройства.
