# #827: предварительные варианты аналитики

Отклонённый владельцем схематичный человек удалён. A показывает список с диаграммой количества выполненных подходов, B — карточки и текстовое участие. Все значения синтетические; периоды и состояния статичны. Фактический источник для будущей реализации — `services/analytics.py`: `muscle_group_workload.current` содержит общее число подходов, отдельно основные и вспомогательные подходы, количество тренировок и частоту за неделю; также доступен `completed_sets_without_muscle_metadata`. Одна группа может иметь оба вида участия: это необходимо показать в реализации. Один подход может относиться к нескольким группам, поэтому показатели групп нельзя суммировать как число уникальных подходов.

PNG получены локально в Chromium и WebKit на 360×800 и 1440×900 в светлой и тёмной темах, без горизонтального переполнения. Макет не подключён к API; проверки реального устройства, скринридера, контраста и предметной корректности не проводились. Это предварительная замена отклонённого макета, не финальный пакет для утверждения.

## Источники анатомии — проверка продолжается

- [MuscleMap, ревизия 170cfac](https://github.com/Jsplice/MuscleMap/tree/170cfacda79376dd59ac0cf2f7dfab8ff9f4443a): [происхождение](https://github.com/Jsplice/MuscleMap/blob/170cfacda79376dd59ac0cf2f7dfab8ff9f4443a/ASSET_PROVENANCE.md) отдельно указывает MIT для `packages/assets/src/{male,female}-{front,back}.ts` и четырёх `packages/assets/bodies/*.webp`; автор сообщает, что векторные пути созданы вручную, а изображения сгенерированы и отредактированы. Это заявление автора, а не независимая экспертиза анатомии. Требуются проверка конкретных областей относительно справочника YFC и визуального качества; файлы в проект не импортированы.
- [js-rich-body-highlighter](https://github.com/crmapache/js-rich-body-highlighter): заявлены восемь изображений и MIT, но отдельное происхождение самих изображений пока не подтверждено. Не использовать до подтверждения прав и проверки областей.
- [react-muscle-highlighter](https://github.com/soroojshehryar/react-muscle-highlighter): заявлен MIT и SVG, но происхождение отдельных изображений и соответствие справочнику пока не подтверждены. Не использовать до проверки.

До изменения runtime UI необходимы законченное исследование, единый пакет кандидатов и явное утверждение владельца. Никакие файлы источников #830/#831/#1201 не использованы.
