# Codex Code Review policy

This file keeps its historical name for durable links. Codex Code Review and automated LLM review
are not part of the repository delivery contract.

Pull requests use deterministic GitHub Checks, including the repository's security jobs. A local
implementer self-review is optional engineering practice, not an external lifecycle gate. The
operational source of truth remains Git, GitHub pull requests, GitHub Checks and GitHub Actions.

See [development.md](development.md) for the normal GitHub Flow and
[deployment.md](deployment.md) for release, smoke and rollback behavior.
