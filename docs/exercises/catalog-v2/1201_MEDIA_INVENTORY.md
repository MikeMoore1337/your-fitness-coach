# #1201: инвентаризация источников медиа

База: `dev` 5041b77c8b29cfc4da26586154165aa734ffa6ef, manifest schema 3. Матрица [1201_MEDIA_INVENTORY.csv](1201_MEDIA_INVENTORY.csv) содержит по строке на каждый из 206 canonical ID. Снимок относится к этой ревизии и не заменяет manifest.

`local_file_status=VERIFIED` означает только, что основной файл manifest прочитан, декодирован Pillow и его SHA-256 совпал с manifest. Размеры и число байт получены из локального файла. Это не проверка движения или прав на другой файл. `semantic_status=REVIEW` означает, что точное соответствие движению в рамках этой инвентаризации не проверено. `gymvisual_hd_original_status=BLOCKED` означает, что оригинал для пилота не предоставлен и не проверен; это не утверждение об отсутствии файла у владельца. Пустой source ID означает, что в текущем manifest нет соответствующего привязанного файла, а не то, что такого продукта не существует.

- 167 основных GymVisual GIF: идентификаторы и локальные хеши указаны в матрице.
- 4 основных файла принадлежат Exercises Media; это не GymVisual ID.
- 35 записей не содержат основного media и отмечены `BLOCKED`.
- Все 171 имеющихся основных файла прошли локальную проверку хеша и декодирования. Другие derivatives не проверялись этим проходом.
- Поля `video_source*` скопированы из manifest и обозначают другой источник; они не подтверждают локальную доступность или происхождение GymVisual HD. Отсутствующий SHA оставлен пустым.

Для трёх разных механик нужны оригиналы, точно соответствующие текущим записям: `squat` — `gymvisual:0043:qXTaZnJ`, `lat-pulldown` — `gymvisual:0197:qdRxqCj`, `burpee` — `gymvisual:1160:dK9394r`. Эти ID относятся к существующим GIF; ID отдельных Full HD продуктов и точное совпадение роликов предстоит установить. Текущие GIF имеют размер 180×180. Оригинальный Basic Grey MP4 или анимированный GymVisual файл 360/720/1080 для этих записей не был предоставлен для проверки. Путь к архиву или три исходных файла нужны для ffprobe, хеширования и визуальной проверки всех фаз. Публичный preview и AI-upscale не являются оригиналом.

Проверены только manifest и указанные им основные файлы текущего worktree; ограниченный поиск по доступным локальным артефактам не является инвентаризацией всех дисков владельца и столкнулся с отказами доступа к некоторым каталогам. Пилот, сравнение воспроизведения, семантическое решение и owner visual acceptance остаются незавершёнными. Runtime и manifest не менялись.
