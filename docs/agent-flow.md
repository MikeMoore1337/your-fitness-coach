# Optional Agent Flow

`scripts/agent_flow.py` is optional local routing assistance. It may infer a small set of roles,
surface-specific skills, a Graphify hint and a bounded host tool budget.

It does not own a branch, Issue, PR, release or deployment; it creates no lease, queue, persistent
lifecycle state or mandatory task mirror. A routing failure falls back to direct source inspection
and ordinary GitHub Flow. GitHub Issue/PR/Checks/Actions remain authoritative.
