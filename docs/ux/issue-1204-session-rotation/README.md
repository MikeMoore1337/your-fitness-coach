# #1204 · Прототип последовательности тренировок

**Это макет, а не работающий продукт.** Данные вымышлены; нажатия не вызывают API и ничего не сохраняют. Визуальное принятие требуется до изменений UI. PR [#1371](https://github.com/MikeMoore1337/your-fitness-coach/pull/1371) слит в `dev` как `34dfd83912b29b2d1e45e83de54bfebf4b836188`.

- [Интерактивный прототип](prototype.html): скачайте весь каталог вместе с `assets` и откройте файл в браузере; вверху можно выбрать сценарий и тему.
- [Архив интерактивного прототипа](session-rotation-interactive.zip) — то же без скриншотов.
- [Рабочий доменный контракт](CONTRACT.md): известные связи, предлагаемые решения и открытые вопросы периодизации/длительности.
- [Галерея для локального просмотра](gallery.html) и [результаты автоматических проверок](checks.json).

Проверка прототипа: 360 сочетаний (18 состояний × 5 ширин: 320, 360, 393, 430, 1440 × 2 темы × 2 движка): наличие заголовка, горизонтальное переполнение, breakpoint dock и открытие диалога. Дополнительно проверены выбор режима клавиатурой, обязательный выбор первого дня, предпросмотр, Escape, подтверждение/возврат после пропуска, отмена/восстановление, offline и выбор вне очереди. Отступ safe-area имитировался CSS; настоящий iPhone/TMA и автоматический аудит контрастности не проверялись.

Источники стиля: действующие дизайн-контракты проекта и [пример существующего экрана «Сегодня»](https://github.com/MikeMoore1337/your-fitness-coach/blob/7ecee28f4c435f9d7c23b23d81917b812c8fbc00/docs/ux/mobile-release-859-914/after/chromium-393-dark-today.png) из предыдущих синтетических browser evidence. Этот пример исторический, не новый снимок актуального dev. Базовые assets и шрифты взяты из `dev` `34dfd83912b29b2d1e45e83de54bfebf4b836188`; лицензии шрифтов и glyphs находятся в `assets`.

Ни приложение, ни база данных, ни текущий Windows DEV этим пакетом не изменены. Периодизация, точное окончание конечной программы, API, права, offline и конкурентность требуют отдельной реализации и проверок после принятия решения.
