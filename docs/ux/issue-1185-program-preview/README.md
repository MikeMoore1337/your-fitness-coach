## Причина и исправление

Общий `.card > * { max-width: 100% }` ограничивал внутренний scroll-контейнер
шириной области панели без padding. При этом шапка использовала отрицательные
боковые margins, выходила за scrollport и создавала 20 px горизонтального overflow.
Горизонтальный жест прокручивал именно `.program-example-modal__content`, после чего
тексты смещались под его левую границу. Это общий CSS-контракт, независимый от программы.
Нижняя панель действий также оставалась ограничена общей шириной дочернего элемента card.

Начальный PR уже исправлял боковую геометрию и ограничивал скрытые заголовки дней.
Новая проверка дополнительно выявила обрезание 2 px кнопки закрытия: sticky-шапка
с `top: -20px` оказалась внутри нового scrollport. Исправлены верхний margin
контейнера и `top: 0; margin-top: 0` шапки. Дизайн, компонент, действия, API и модель данных сохранены.
Новый `overflow-x: hidden`, фиксированная ширина устройства и второй скролл не добавлены.

Контрольный CSS-эксперимент на master: исправление только боковой геометрии меняет
контент с 298/278 на 318/318, но сохраняет обрезание закрытия; отдельное исправление
верхнего края устраняет обрезание. Это измерение в браузере, а не вывод по CSS-тексту.
