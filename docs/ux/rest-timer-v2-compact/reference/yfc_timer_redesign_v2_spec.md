# YFC · Таймер отдыха · компактный редизайн v2

## Статус
Визуальная концепция v2 для согласования владельцем. Само приложение YFC не изменено.
Прототип локальный, демонстрационный, не подключён к серверу. Код/PR/merge/deploy: NOT_RUN.

## Задача
В первом варианте таймер занимал 235 CSS px при активном отдыхе, 296 px при ошибке сохранения, 256 px при восстановлении. Эти состояния заслоняли ввод веса и повторений.

## Компоновка
- Фиксированная верхняя панель, два ряда без пустых карточек. Верх: остаток по плану (высокая визуальная важность), фактическое время, состояние и стрелка сворачивания. Низ: четыре действия `+30 сек`, `+60 сек`, `Стоп`, `Пропустить`.
- Нет отдельной полосы прогресса, повторного названия упражнения или декоративных элементов, занимающих высоту. Следующий подход уже доступен в карточке тренировки.
- Плановое 0:00 не завершает фактический отдых автоматически. `Стоп` фиксирует по действующему контракту; `Пропустить` не создаёт фактический замер.
- Сворачивание оставляет 60-px строку с текущими значениями и «Развернуть»; это только изменение представления, не остановка интервала.
- Завершение/пропуск/исключение: одна строка 66 px, «Новый отдых» и «Скрыть» справа. Повторный запуск - новый интервал, прежняя история остаётся.
- При offline, saving, pending, 409, обычной ошибке: время и четыре действия остаются на месте, меняется компактная надпись справа; подробности и повторы - в отдельном диалоге, не раздувают панель.
- Если после длительного отсутствия требуется уточнение фактического отдыха: закреплённая строка 62 px, редактирование в явном диалоге по касанию. В фоне время не считается подтверждённым автоматически.
- Light/Dark и узкие 320/360/393/430 px. Целевая зона касания всех кнопок ≥44×44 CSS px.

## Верификация именно визуального прототипа
- Chromium (headless): 160 сочетаний размеров/тем/состояний, PASS.
- Проверено: горизонтальный overflow, размеры кнопок, читаемость времени без обрезания, отсутствие перекрытия dock, неподвижная панель при прокрутке содержимого, панель не выше 118 px, повторный запуск и сворачивание, изменение +30, stop/skip, открытие синхронизации и восстановление времени.
- WebKit: NOT_RUN (движок отсутствует в текущей среде).
- Физический iPhone, Safari, PWA, Telegram TMA, VoiceOver: NOT_VERIFIED.
- Реальная работоспособность, offline-очередь, backend/миграции, click-through, фактическая точность таймера: NOT_VERIFIED. Демонстрационные переходы не доказывают поведение продукта.
