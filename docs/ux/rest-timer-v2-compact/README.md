### Результат визуального сравнения

Два ряда, порядок действий, акцент «Стоп», положение часов, отсутствие дублирования упражнения,
отдельная форма уточнения и высоты совпадают с v2. Максимальная ширина панели — 640 CSS px.
Сохранены реальные токены YFC, матовый материал, радиусы, Inter/Oswald и общие иконки.
Карточки подходов и нижняя навигация не переделаны. В макете окружающая страница упрощена,
поэтому она отличается от настоящего интерфейса и не является предметом копирования.

Ограничения точного пиксельного совпадения: запрещённая проектным AGENTS.md односторонняя
лаймовая полоса 3 px из прототипа не перенесена; рамка панели равномерная. Использован
действующий формат времени YFC `M:SS`, а не демонстрационный `MM:SS`. Цвета и радиусы кнопок
взяты из приложения. Диалог использует общий Oswald-заголовок и общий фокус YFC.
Эти различия показаны на сравнениях; утверждение о полном попиксельном совпадении не делается.

## Изменения и сохранённые гарантии

- `TodayWorkout.tsx`: только представление RestTimer, общие модальные компоненты,
  доступные имена, фокус/возврат фокуса/Escape и компактные статусы.
- `react.css`: стили таймера и его диалогов. Фиксированная панель и измеряемый spacer
  применены также на desktop, чтобы блокировка прокрутки диалогом не сдвигала таймер.
- `RestTimer.test.tsx`, `active-workout-experience.spec.ts`, `liquid-glass-system.spec.ts`:
  новые состояния и геометрия, существующие проверки данных и касаний сохранены.

Исправлены два выявленных при проверке дефекта представления: WebKit мог применить новую
высоту spacer после восстановления позиции карточек; теперь существующий ResizeObserver
восстанавливает якорь после фактического изменения высоты. Продолжение двойного клика
по новому запуску больше не открывает случайно появившуюся на том же месте кнопку диалога.
Диалог уточнения привязан к идентификатору интервала и не переносится на следующий отдых.
Общий offline-баннер скрыт только при наличии равнозначного статуса в активном/свёрнутом
таймере: он перекрывал часы. В остальных экранах баннер сохранён; тест проверяет обе ситуации.

`restSessions.ts`, журнал синхронизации, backend/API/БД и зависимости не изменены.
Сохранены абсолютный deadline, расчёт факта, восстановление, очередь, идемпотентность и 409.
Регрессии проверяют вес, повторы, RIR и completed у текущего, завершённого и соседнего
подходов после действий с таймером; старые интервалы сравниваются целиком.
