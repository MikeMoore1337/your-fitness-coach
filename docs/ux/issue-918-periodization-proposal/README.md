# Issue #918: макеты настройки периодизации

**Статус: предложение для визуального согласования.** Это не работающий интерфейс периодизации и не AFTER реализации. База текущего интерфейса — dev [106f75ab13ca6cc788817bdb7502352ce0dd3aba](https://github.com/MikeMoore1337/your-fitness-coach/commit/106f75ab13ca6cc788817bdb7502352ce0dd3aba). Все имена и тренировки в примерах синтетические.

Открывайте PNG по ссылкам ниже. [HTML-макет](index.html) можно сохранить вместе с папкой fonts и открыть локально: верхний селектор переключает состояния и тему; кнопки действий служат для показа и не сохраняют данные.

## Решение

- Сохраняется редактор «День в центре». Периодизация включается в существующих настройках программы; по умолчанию она выключена.
- Исходный цикл и срок назначения задаются отдельно. Срок остаётся тем же значением, что в расписании программы; отдельного второго состояния для него не создаётся. Тип каждой недели может быть не задан. В примере первые две недели тяжёлые; это не означает отказ или изменение нагрузки.
- Повтор включается явно. Без повтора срок не превышает длину исходного цикла. Предпросмотр показывает номер программы, исходную неделю, проход, тип и тренировки.
- Для будущего изменения упражнения или типа показаны одна неделя, будущие повторы исходной недели и выбранные недели. Перед применением показываются затронутые тренировки и предупреждение об истории.
- В предложении отключение действующей программы с выбранной границы сохраняет оставшиеся тренировки на текущий срок, выключая дальнейшие типы и повторы. Начатые и завершённые тренировки остаются без изменений. Это предлагаемое поведение ещё требует реализации и проверки серверного контракта.
- Для программы тренера остаются проверка прав и отдельное назначение. Типизированная история и общие рекорды не объединяются; при недостатке данных показывается причина.
- Импорт представлен как ручной выбор типов, без предположения о типе по цвету. Парсинг XLSX остаётся за #872.

- Сборка текущего frontend на базовом SHA и 10/10 браузерных сценариев исходного редактора на пяти ширинах и двух темах; ранее отдельный проектный тест прошёл 4/4.

- В оболочке приложения 12/12 сценариев Chromium для Web и имитаций PWA/TMA: две темы, настройка и проверка изменений; видимость действия и отсутствие его пересечения с нижней панелью на 393 px.
- Настоящая мобильная клавиатура, screen reader, физический Telegram, сохранение/API/БД, regression и CI новой реализации ещё не проверены.

## Подтверждённые границы текущего backend

- [Схема цикла](https://github.com/MikeMoore1337/your-fitness-coach/blob/106f75ab13ca6cc788817bdb7502352ce0dd3aba/backend/fitminiapp_api/schemas/program.py#L511) принимает типы для всех недель или отсутствие списка, но не смешанный список с отдельными null. Локальная проверка: два первых варианта приняты, смешанный отклонён. [Резолвер истории](https://github.com/MikeMoore1337/your-fitness-coach/blob/106f75ab13ca6cc788817bdb7502352ce0dd3aba/backend/fitminiapp_api/services/program_versioning.py#L470) также распознаёт только полные списки; изменение схемы без этой проверки может сделать тип неизвестным.
- [Обновление шаблона](https://github.com/MikeMoore1337/your-fitness-coach/blob/106f75ab13ca6cc788817bdb7502352ce0dd3aba/backend/fitminiapp_api/services/programs.py#L1303) сейчас отклоняет заданный week_cycle. Включение, изменение и отключение в существующем шаблоне требуют точечного расширения.
- [Области #920](https://github.com/MikeMoore1337/your-fitness-coach/blob/106f75ab13ca6cc788817bdb7502352ce0dd3aba/backend/fitminiapp_api/services/program_versioning.py#L2650) проверены для правки упражнения; для отдельного типа и server-authoritative preview аналогичный готовый контракт не подтверждён. Нельзя выдавать предложенный экран за уже доступную возможность.
- Недельные предписания присутствуют в [ответе шаблона](https://github.com/MikeMoore1337/your-fitness-coach/blob/106f75ab13ca6cc788817bdb7502352ce0dd3aba/backend/fitminiapp_api/schemas/program.py#L565), но их сохранение через существующий редактор требует отдельной проверки, чтобы не сгладить исходный план.
