# #920 — AFTER редактирования назначенной программы

Снимки показывают реальный frontend из commit `457902e3b32a1c026c78655451df5be03eddad81` с синтетическими API-ответами. Данные пользователей DEV не использовались. Playwright: Chromium и WebKit, viewport 393 × 900 и 1440 × 900 px, тёмная и светлая темы. Снимки показывают компонент целиком; закреплённая навигация приложения видна там, где она находится в браузере.

В принятом макете состав дней и выбор области показаны отдельными экранами. В этой реализации они находятся внутри существующей панели периодизации; все фактические состояния представлены ниже. Требуется отдельная визуальная приёмка этого AFTER. Физические устройства и настоящий Telegram не проверялись.
