# #906 — визуальное предложение Hero для QHD

Статус: историческое предложение до owner approval. Актуальный итог: вариант B визуально одобрен и реализован в PR #944; production release отдельно не разрешён.

Два настоящих варианта поверх одной изолированной локальной сборки опубликованы в [evidence/906/README.md](../evidence/906/README.md): `/for-athletes` и `/for-trainers`, 2560×1440 в обеих темах, а также контрольные 1920×1080 и 1440×900. Для каждого кадра доступны `BEFORE`, A и B; provenance закрепляет runtime SHA, viewport, browser и временный CSS overlay.

`frontend/src/pages/landing/landing-v10.css` сейчас оставляет desktop Hero около `860px`; одного `object-position` недостаточно, пока контейнер остаётся низким.

| Вариант | Параметры локального предложения | Плюсы | Минусы |
|---|---|---|---|
| A — conservative | `900px`, focal position `65% 34%` | Меньше сдвиг первого экрана, раньше следующий раздел | Верхний силуэт и оборудование ближе к границе кадра |
| B — cinematic | `980px`, focal position `65% 27%` | Спокойнее кадрирование лица, рук и оборудования на QHD | Больше вертикальный первый экран и скролл |

Владелец выбрал вариант B. Native browser zoom 125% остаётся непроверенным; merge и deployment по-прежнему запрещены отдельным release gate.
