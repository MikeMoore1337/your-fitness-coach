# Финальная правка #978 - нижняя лаймовая грань в Light

**Основание:** владелец принял остальной пакет PR #1000, но отклонил только недостаточно заметную нижнюю лаймовую грань выбранного ответа «Самочувствие» в светлой теме.

## Исправление

- В **Light** выбранный radio-вариант получает явную **3 px лаймовую нижнюю границу** плюс **2 px внутреннюю лаймовую полосу**, отрисованную поверх рельефа, а не под ним.
- **Dark без изменений**: прежний вид с лаймовым акцентом сохранён.
- Применяется только к `.daily-wellbeing__option[data-yfc-choice='compact']:has(> input:checked)` в светлой теме; другие элементы, кнопки, фон и поведение не менялись.
- Используется существующий `--v2-lime`, а нативные `input[type=radio]`, доступность, часы сна и однострочные действия остаются прежними.

## Автоматические проверки

- Chromium + WebKit, Dark + Light, ширины 320/360/390/430 px: проверены `border-bottom-color`, точная ширина границы (3 px в Light, 1 px в Dark), порядок lime-shadow, сохранность выбранной/невыбранной радио-семантики и корректное расположение двух нижних кнопок в один ряд.
- [Измерения Chromium](chromium-computed-320-430.json) и [измерения WebKit](webkit-computed-320-430.json) содержат `selectedBorder` и границы элементов для всех 8 сочетаний в каждом движке.
