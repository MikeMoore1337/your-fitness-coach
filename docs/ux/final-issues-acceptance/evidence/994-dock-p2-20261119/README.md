Для проверки реального zoom Chromium масштаб вкладки установлен в 200%; исходные 320, 360, 390, 393 и 430 px соответствуют 160, 180, 195, 196 и 215 CSS px. Дополнительно проверены 640 исходных px / 320 CSS px. На отдельном листе «Узкий CSS viewport» использованы такие же размеры CSS viewport и DPR 2: это имитация для читаемого снимка после прокрутки, а не доказательство настоящего zoom. Настоящий zoom проверялся отдельно по значению браузера и измерениям геометрии, включая все три действия Today и пять действий Quick Add после прокрутки.

Проверки включают доступные имена пяти элементов, размеры областей касания, видимость текста, selected/focus/pressed, открытие и закрытие Quick Add, возврат фокуса, Active Workout и сохранение навигации, а также имитацию safe-area. Disabled для пяти элементов dock не применяется. Desktop, Coach OS и Demo проверены отдельно. В WebKit доступное окружение пропускает ссылки при Tab и на исходном dev; без дополнительных доказательств это не классифицируется как регрессия изменения.

Для вертикального содержимого [WCAG 2.2 Reflow](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html) использует ширину 320 CSS px; меньшие viewport здесь являются дополнительными практическими проверками. [Resize Text](https://www.w3.org/WAI/WCAG22/Understanding/resize-text.html) рассматривает увеличение текста до 200% отдельно. Этот пакет не является полной оценкой соответствия WCAG.

Сочетание базового шрифта 32 px, настоящего zoom 200% и минимальной физической ширины — дополнительный стресс-тест по решению владельца; его результат не определяет визуальную приёмку основной матрицы. **FAIL:** в четырёх проверках при исходной ширине 320 и 393 px в обеих темах основное действие Today выходит за правый край viewport 160 и 196 CSS px. В Active Workout при увеличенном шрифте обрезается заголовок; на странице «Прогресс» — подписи отдельных элементов. Оба ограничения видны и в согласованном прототипе; эти страницы не входят в объём адаптации содержимого Today. Физический iPhone, VoiceOver и настоящий Telegram: **NOT_VERIFIED**.

Визуальное принятие AFTER предшествует действиям в dev и обновлению Windows dev; оно не подтверждает production или весь оставшийся объём V14.
