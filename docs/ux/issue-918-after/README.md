# Issue #918: реальные AFTER

Снимки рабочего React-интерфейса на синтетических ответах API. Это пакет для отдельной визуальной приёмки, а не подтверждение работы production, физических устройств или реального Telegram.

Chromium и Playwright WebKit; обе темы; окна 320/360/393/430 × 852 и 1440 × 1000 CSS px. Плотность снимков Chromium — 1, WebKit — 2 физических пикселя на CSS px. Снимки области компонента могут быть выше или уже окна; фиксированная навигация может попадать в длинный снимок. Снимки оболочки показывают фактический viewport. Предыдущее состояние редактора — в [пакете до/макетов](../issue-918-periodization-proposal/README.md#существующий-интерфейс-до).

В примерах включена периодизация K=3, N=16 с двумя соседними тяжёлыми неделями и незаданным типом третьей. Предпросмотры и конфликты намеренно используют синтетические данные, в том числе защищённую завершённую тренировку.

## Проверки и границы

- PostgreSQL/API: 144 теста циклов, конкурентных ревизий, типов и сохранения истории.
- Chromium и WebKit: по 63 сценария интерфейса, затем 20 сценариев активной программы после исправлений; дополнительно 20 сценариев отображения текущей недели в двух движках. Проверена имитация уменьшения viewport при фокусе числового поля.
- Chromium: 10 сценариев фактической прогрессии/истории #917, штатная UI-проверка 3/3. Vitest: 1 179 тестов; TypeScript, lint, сборка и бюджет размера прошли.
- Физическая мобильная клавиатура, реальные устройства/Telegram, screen reader и DEV после merge не проверялись. Локальные браузерные имитации и тестовые API не доказывают production.

**Решение владельца:** принять ли этот комплект AFTER для отдельной визуальной приёмки? Такое принятие не является разрешением на release или production.
