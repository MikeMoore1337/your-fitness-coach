## Условия получения

- Создание и назначение программы, сохранение подходов, отмена/восстановление и завершение выполнены через локальный API; пользовательские данные не использовались.
- Для состояний перерыва и окончания срока даты изменены только в синтетической тестовой базе. Связь с тренером также создана в ней.
- Конфликт 409 вызван вторым тестовым клиентом; offline — отключением сети браузера; ошибка загрузки — намеренным ответом 503. Для перехвата ошибки service worker в браузерной сессии отключён.
- Для статических снимков переходы и анимации отключены, чтобы показать конечные цвета после смены темы.
- Реальный путь создания и назначения через конструктор, включения очереди и завершения тренировки проверен отдельно. После завершения показана следующая тренировка.
- Горизонтальное переполнение проверено на 320, 360, 393, 430 и 1440 px в Chromium и WebKit. В имитации TMA проверены safe-area, клавиатура и нижняя панель.

Нужна визуальная приёмка владельца этого полного пакета. Она не является разрешением на merge или выпуск.
