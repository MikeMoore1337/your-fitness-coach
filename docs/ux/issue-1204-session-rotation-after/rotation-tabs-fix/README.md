Исправление в [PR #1380](https://github.com/MikeMoore1337/your-fitness-coach/pull/1380), код [21c745b3](https://github.com/MikeMoore1337/your-fitness-coach/commit/21c745b3719fbb04dbc3a6400cf8ef78c290be83). Варианты занимают равные половины доступной ширины.

Это не проверка физического устройства или настоящего Telegram.

Геометрия обеих кнопок, высота не менее 44 px, размещение текста, клавиатура и отсутствие горизонтального переполнения проверены на 320/360/393/430/1440 px; для программы тренера проверены равная ширина и недоступное состояние. В тестах используются те же фиктивные ответы API.
