# Issue #1052: компактные карточки кардиосессий

Эта папка содержит синтетические BEFORE/AFTER-кадры для изменения карточек завершённых кардиосессий в разделе «Прогресс → Кардио».

## Контекст evidence

- BEFORE: чистый `origin/master` на SHA `396bae69530d6d21c2de89b11daa2d48c3f824d5`.
- AFTER: ветка `codex/1052-compact-cardio-session-cards`.
- Данные: браузерная фикстура без пользовательских данных, фиксированная дата `2030-01-30`, три завершённые сессии.
- Первая сессия намеренно не содержит среднего пульса, дистанции, зоны или заметки. Это проверяет, что интерфейс не создаёт фиктивные значения.
- Кадры сняты в Chromium на ширинах 393 и 1440 пикселей для Light и Dark. В кадр попадает первая сессия; остальные состояния проверяются адресным Playwright-тестом.

## Проверяемый объём

- имя, статус, дату и время;
- компактную группу длительности и среднего пульса, только если значение известно;
- дополнительные показатели через раскрытие;
- существующее раскрытие «Действия с записью», редактирование и удаление с подтверждением;
- отсутствие горизонтального переполнения и перекрытия мобильным dock после прокрутки к карточке.

Общий layout Progress, навигация, API-контракты и база данных в этой задаче не изменяются.
