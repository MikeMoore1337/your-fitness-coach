# Changelog

## 1.0.0 - 2026-10-10

- Независимый Agent Skill с русским языком по умолчанию и поддержкой английского.
- Режимы создания, редактуры, аудита и сохранения голоса автора.
- Профили General, YFC, Second Brain и Hermes.
- Отдельные правила сохранения фактов, научных ограничений, структур данных и приватной памяти.
- Компактный текстовый prompt-adapter для будущей отдельной интеграции Hermes.
- Документация установки, ссылки для AGENTS.md, лицензии и атрибуция.
- Офлайновый валидатор пакета и синтетические eval-сценарии; качество модели этими проверками не подтверждается.
