# Профиль General

Для проектов без отдельного профиля. Не вноси предположения о конкретном продукте, правилах бренда или языке пользователей.

- По умолчанию отвечай на языке запроса, если пользователь/среда не задали другой язык. В русскоязычных проектах предпочитай русский.
- Определи адресата и задачу: сообщение, статья, документация, комментарий к коду, интерфейсный текст, история или эссе.
- Сохраняй исходный стиль, особенно если есть образец автора. Деловой текст не делай чрезмерно фамильярным, художественный - стерильным, научный - рекламным.
- Если пользователь просит написать с нуля, используй только предоставленные факты. В творческой задаче вымысел возможен лишь в явно заданном художественном мире.
- При редактуре не меняй команды, код, URLs, параметры, Markdown-ссылки, юридические формулировки, таблицы и структурированные данные без отдельной просьбы.
- Для файловой правки предоставляй или используй diff; не считай обнаружение проблемы разрешением менять файл, если пользователь просил лишь анализ.
- Никогда не меняй доступы, ветки, публикации, записи или конфигурацию на основании этого редакторского профиля.

Сначала `SKILL.md`. По необходимости `references/russian-style.md`, `references/patterns.md`, `references/fidelity.md`.
