# Clear Voice 1.0.0

Самостоятельный переносимый Agent Skill для создания, редактирования и проверки естественных русских текстов. Английский поддерживается вторым языком. Работает без сети, модели-провайдера, токенов, базы данных и фонового процесса: инструкции применяет агент, в который скилл установлен.

Создан как оригинальный синтез принципов проектов [human-writing](https://github.com/codemistake/human-writing) и [humanizer](https://github.com/blader/humanizer) с отдельными профилями Your Fitness Coach, Second Brain и Hermes. См. `SOURCES.md`, `THIRD_PARTY_NOTICES.md`.

## Быстрый старт

1. Скопируйте **всю** папку `clear-voice/` в каталог скиллов агента, например `<project>/.agents/skills/clear-voice/` (для YFC путь уже используется).
2. Убедитесь, что существует `<project>/.agents/skills/clear-voice/SKILL.md` и все соседние файлы.
3. В задаче напишите: «Примени `$clear-voice` к тексту для YFC» или «Проверь черновик через `$clear-voice`, профиль Second Brain, режим аудит».
4. Профиль `general` применяется вне конкретных проектов. При активном проекте агент выбирает подходящий профиль из `profiles/`.
5. При ручной интеграции проекта читайте `INSTALL.md`. Для runtime Hermes - `adapters/hermes/README.md`.

Не копируйте содержимое всех профилей в `AGENTS.md`: это вызывает дублирование правил и трату контекста. Достаточно короткого указателя из `examples/AGENTS.snippet.md`.

## Возможности

- Создание текста, мягкая редактура, аудит, точечное исправление, адаптация под образец стиля.
- Защита смысла, дат, чисел, причинно-следственных связей, доказательной неопределённости и структурированных полей.
- Профили для пользовательских текстов YFC, личной базы знаний Second Brain и научных новостей Hermes.
- Использование в стороннем проекте без переименования или удаления брендовых профилей.
- Самодостаточный офлайн-набор синтетических контрольных сценариев.

## Чего нет

- Исполнения в Hermes автоматически после установки в Codex.
- Подключения к другим приложениям без действия владельца.
- Проверки научных данных «по кнопке» без исходных материалов и профильных проверок.
- Полноценного живого бенчмарка LLM, гарантии улучшения текстов или обхода AI-детекторов.
- Изменений исходных репозиториев, базы знаний, пользовательского vault, GitHub Issues/PR и production.

## Проверить комплект

```bash
python clear-voice/evals/validate_package.py
```

Валидатор использует только стандартную библиотеку Python и ничего не пишет. Он проверяет формат, ссылки, структуру и тестовые входы, но не может оценить фактическое качество текста модели. Для LLM-сравнений см. `evals/README.md`.

## Пример использования

> Проверь текст для Hermes с `$clear-voice`, режим аудит. Не перефразируй данные исследования и не меняй источники. Покажи только конкретные проблемы и безопасные формулировки.

> Напиши короткую подсказку для создания программы тренировок в YFC. Используй `$clear-voice`, профиль YFC; все пользовательские строки на русском, без обещаний результата.

> Отредактируй только `content` черновика Second Brain; сохрани title, note_type, tags, links, ссылки и факты без изменений. Не записывай в vault.
